# Typefield 0.59.10 (90) window QA

## Behavior

- Spaces and Letterform Editor each retain one live editing session while moving between the main window and a separate resizable/fullscreen window. Pop out, header-grip tear-off, Dock window and close-to-dock share this path.
- Letterform pop-outs default to Focus editor. Project navigation, project header and proof strip are hidden; character width remains adjustable, Characters hides that rail, and Metrics expands/collapses spacing controls. Full workspace restores the surrounding UI.
- Command-N creates independent font browsers. Each has its own scope, search, preview and style selection. Sources include collections, folders, favorites and the shortlist, with explicit open-in-window actions for collections and the shortlist.
- Font drags identify an installed PostScript face. Dropping on text replaces that role or the exact imported text layer while preserving text, geometry and unrelated styles. The saved change participates in Spaces undo/redo.
- Type role carries an info button for editing-scope help instead of the persistent explanation.

## Checks

- `./install-local.sh`: optimized native suite, 21,260 layouts, 778 families / 4,252 styles; canonical installation.
- `--window-self-test`: same host through repeated detach/dock/close, no duplicate editor, fullscreen/resizing capability, independent browser lifetime, typed payload parsing and oversized/plain-text rejection.
- Native Spaces regression fixtures: role-specific and imported-layer font replacement, unchanged content/geometry, rejected blank target, persisted undo/redo.
- `node tests/figma-import.test.js`: passed mocked Figma bridge.
- Website JavaScript syntax and `python3 scripts/check-beta-website.py`: passed.
- Live disposable `--window-qa` fixture on the window candidate (the merged release retains the same window code): separate Spaces and Letterform windows, browser creation/search independence/close/fullscreen, focused character/metrics controls, editing-scope info popover, four-node outline creation followed by docking and successful Undo/Redo.

- The live font-drag diagnostic confirmed `CourierNewPSMT` is emitted by the browser. Automated cross-window gestures did not reach the destination callback, so an end-to-end physical mouse drop remains a manual verification gap; the native role/layer replacement and undo/redo tests passed. QA-only stderr diagnostics are available with `--window-qa`.

## Preservation and limits

The two pre-existing research evaluator edits remain separate and uncommitted. No research was resumed. User-font registration and production activation cleanup are disabled in the disposable window fixture. All 27 baseline saved user JSON hashes remained unchanged. This targeted pass does not replace VoiceOver, second-Mac/macOS 13, external Figma service or notarization testing. The beta remains ad hoc signed for Apple silicon, without Developer ID notarization.

The final release integrates the concurrent 0.59.9 variable-font exporter and first-party feedback website. The superseded local 0.59.9 window candidate was not published.
