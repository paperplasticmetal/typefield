# Typefield 0.59.5 performance cleanup

Date: 2026-10-05 (Pacific). Candidate: **0.59.5 (85)**, from `31f33f5` (0.59.4). Local ad hoc signed Apple Silicon build; not a public distribution release.

## Review and changes

The review covered Library catalog/filter/preview and similarity paths; Spaces plan/render/inspector and persistence paths; Letterform vector editing, linked components, import/fitting, model persistence and TrueType export; folder watching, font downloads, backup/recovery and Figma import; and release build settings. The source inventory contains approximately 30,000 Swift lines including native checks and embedded export scripts. This was a performance-focused review, not exhaustive certification of every interaction.

- Library retains one current filtered-family snapshot and its matching-style count. Changes to catalog, search, filters, tags, saved state and pro state invalidate it; predicates that inspect live font activation bypass it. The first scan computes the footer count too; repeated UI reads avoid rescanning and sorting.
- Similarity ranking generates explanatory strings only for returned families. Search parsing reuses its constant regular expression.
- Letterform editing reuses converted paths until glyph data changes. Curve hit testing rejects distant control bounds and reuses adjacent samples. Selection, geometry, tolerances, undo and export formats are unchanged.
- Glyph Browser computes filtering and the preview font once per view evaluation, does not repaint equivalent native glyph views, and checks SVG availability without serializing the entire SVG.
- Trace validation precomputes segment geometry, conservatively rejects distant bounds, and sorts crossing candidates spatially. Exact distance/crossing tests remain authoritative; fitting tolerances are unchanged.
- Linked empty glyph trees reuse successful empty resolutions while preserving nesting-depth and cycle rejection. An eight-level graph with 16 repeated links at each level previously revisited empty subtrees exponentially despite the point budget.
- Canvas previews account for retained artwork memory in their cache budget. Obsolete artwork import scans are canceled and stale results cannot update a replacement scan.
- Figma imports resolve repeated font family/style requests once per import, retaining first-match ordering, case-insensitive matching and per-layer missing-font warnings.

No features, recovery safeguards, user fonts, saved projects or paused research code were removed. The pre-existing evaluator edits remain outside this release.

## Verification

- Standalone optimized comparison of the original and final trace predicates passed **1,500 deterministic random fixtures** (seed 73411). A 4,000-point circle measured **22.7 → 5.63 ms** for proximity validation and **16.38 → 0.094 ms** for crossing detection. These are isolated algorithm timings, not import end-to-end timings.
- The native stress checks passed: 200,000-character board layout, 30,000-anchor fitting, vector editing/undo and export, component/kerning/master isolation, and the retained starter checks. A 10,000-anchor fixture measured **14.43 ms uncached / 0.003 ms cached** for 100 path reads; the eight-level, 16-way empty-component fixture validated in **0.163 ms**.
- The first build was invalidated by source edits while compiling. The next native run stopped at a new redraw assertion because an unattached AppKit view does not report dirty regions. The test now checks the rendering update decision directly without opening a desktop window; the isolated native redraw check passes. The installation script stops before copying on a failed check.
- `./install-local.sh` ran `build.sh` with the optimized arm64 build and the complete native suite successfully, then installed **0.59.5 (85)** at `/Applications/Typefield.app`. The suite passed across **778 families / 4,252 styles**, including artwork topology/retention, cancellation, redraw decisions, filter invalidation, Figma font resolution, image cache budget/eviction, undo and persistence. The 33 responsive canvas checks passed.
- `node tests/figma-import.test.js`, both plist lint checks and `git diff --check` passed. The Figma API is mocked; no live external editor round trip is claimed.
- Strict deep signature verification passed. Installed and tested executable SHA-256 both equal `de58617d0bdf055cc2b57ce6dc11572a72b1edf37f6952aef0a7300d5c46b1b9`; the executable is native arm64.
- All **six existing saved JSON files** matched their starting SHA-256 values. The two pre-existing research-file diffs remained byte-identical and are excluded from the commit.

### Full-catalog timings

Both runs used the full 778-family / 4,252-style catalog with disposable project fixtures. Single-run timings are directional and sensitive to OS cache/load.

| Path | Installed 0.59.4 baseline | Installed 0.59.5 |
| --- | ---: | ---: |
| Library filter, repeated unchanged reads | 3.859 ms/read | 0.000770 ms/read |
| Fresh filter + matching-style count | Not measured together | 15.304 ms/read |
| Similarity rank | 5.679 ms | 5.579 ms |
| Pairing rank (unchanged algorithm) | 11.454 ms | 12.347 ms |
| Catalog scan (unchanged algorithm) | 3,505.92 ms | 2,733.57 ms |
| 200-board fresh store load, median | 7.557 ms | 7.888 ms |
| 200-board selection save, median | 7.591 ms | 8.118 ms |

The new cold filter also calculates the style count formerly calculated separately by the UI. Its 15.304 ms therefore must not be compared directly with the old filter-only 3.859 ms as equivalent work. The measured benefit is avoiding repeated scans for unchanged state. Small differences in unchanged pairing/load/save paths are not evidence of an improvement or a diagnosed regression. No cold-launch, frame-rate or energy improvement is claimed. Private logs, baseline hashes and the starting dirty-file diff are under `.context/qa-artifacts/performance-0595/`; the geometry comparison harness is under `.context/qa-artifacts/performance-2026-10-05/services/`. These artifacts are not committed.

## Limitations

Microbenchmarks describe individual paths, not whole-app frame rate, energy use or a universal speedup. Font catalog access differs inside the execution sandbox; full-catalog measurements must be compared separately. Live Figma/Adobe host round trips, a second Mac/macOS 13 pass and a complete UI interaction matrix are outside this pass. Folder watching retains its existing background polling and recovery behavior. Cancellation is cooperative: active synchronous image decoding, simplification or Vision OCR may finish its current call before stopping. The 128 MiB artwork budget applies to retained cache entries, not the active document or the whole process. Missing-letter synthesis remains paused and hidden.
