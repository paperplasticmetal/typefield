# Typefield 0.59.8 beta verification

Build 88 was prepared on 2026-10-06 for direct website download and a versioned GitHub release. It targets Apple silicon and macOS 13 or newer. The app has an ad hoc code signature, no Developer ID identity, and no notarization. There is no app account, activation key, or purchase gate.

## Checks

- `./install-local.sh` passed the optimized native self-test and installed one canonical `/Applications/Typefield.app`. The run covered 21,260 font layout cases across 778 families and 4,252 styles, plus Library, Spaces, Letterform Editor, import/export, recovery, and settings checks.
- `node tests/figma-import.test.js` passed with the Figma API mocked. Live Figma and Adobe host-app round trips were not performed.
- `codesign --verify --deep --strict` passed on the built app and app inside the mounted DMG. The installed, built, and DMG executables share SHA-256 `0cc69636f6f28bf64337f154365955525069517aaba3a959b8169737e96bef21`.
- `bash package-beta-dmg.sh` produced `dist/Typefield-0.59.8-beta.dmg`. `hdiutil verify` passed. A read-only mount contained Typefield 0.59.8 (88) and an Applications shortcut. DMG SHA-256: `b88c47307013e4e255ad9a37cd586344d53354e7ce2a0f6675843ef570b7c79f`.
- The 27 saved JSON files under the existing FontShelf support folder retained aggregate SHA-256 `99e9914c8b947d385fc37b0fc2c5d3fd1617fac97b830bf66050a619cd052a58` after installation, matching the pre-install baseline.
- In-app Feedback and Report a Bug links target separate public issue templates at `paperplasticmetal/typefield-feedback`. The tracker accepts reports from GitHub users without access to the source repository.

## Remaining limits

No clean second-Mac install or macOS 13 first-launch test was performed. The macOS first-open exception was not applied on this Mac. Website and GitHub distribution checks are tracked separately from this local build verification. This beta is not an App Store, TestFlight, Developer ID, or notarized release.
