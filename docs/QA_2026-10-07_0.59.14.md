# Spaces alignment and selection — 0.59.14 (94)

## Repairs

Alignment previously targeted mutable content bounds while automatic artboard sizing added another 12-point margin. Repeated right/bottom alignment therefore enlarged the canvas. Alignment now uses the rendered artboard and composes translations with existing object transforms; automatic overflow protection measures actual content without adding a new margin. Imported canvases use their current explicit width/height rather than the original imported dimensions.

Select/Marquee had a separate object selection that cleared the layer/text selection read by the inspector. Selection now lives in the shared editor session and updates the corresponding layer/text/role. Multiselection clears stale single-object controls. Arrangement label clicks previously entered a text branch with no callback; the whole row now selects its canvas content. The list is a disclosure group, and its native view uses an arrow cursor; I-beam regions are restricted to editable text in Text mode.
