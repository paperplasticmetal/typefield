## Installed interaction review

- **Library at 980 points:** Search remains usable with a shorter visible placeholder and a full accessibility label. Short one-letter previews use less card height, style counts are readable, and card actions remain available. The long/multiline preview path was preserved in source but was not replayed with the user's saved preview text.
- **Spaces at 980 points:** Full inspector and two-row toolbar remain visible. Fit width leaves room for the right canvas resize handle and no longer creates a horizontal scrollbar on the inspected tall website canvas. Selected Space/canvas outlines and the editing-scope panel are visible.
- **Letterform Editor at 980 points:** The empty word proof is compact, project actions occupy a separate row, and the character/editor headers are visible. Clear, Undo/Redo, Simplify outline and Paths are fully visible. Vector tools and selection controls use separate rows, with no horizontal scrollbar. Metrics open in a disclosure with the guide and sliders reachable. This was replayed in the final installed build using the existing 710-point A glyph without editing or saving it.
