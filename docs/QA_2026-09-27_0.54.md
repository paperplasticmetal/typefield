The user authorized improvements first, followed by an adversarial audit whose findings are to be reviewed before debugging. This document covers the improvements. The separate stress-audit report records unfixed findings. Personal projects, fonts, private screenshots and diagnostic artifacts are not committed.

Changes retained:

- Construction strokes can extend beyond their temporary horizontal box before final normalization. Premature validation previously caused some wide ends/diagonal joins to retry at thinner weights.
- G can reuse O's actual bowl with an aperture, crossbar and spur when C is absent. Q's added tail may expand the horizontal box while preserving the physical source curves, instead of discarding the source adaptation.
- i/j stems reach x-height; dot placement and the j descent are corrected.
- Suggestions are explicitly experimental, generate outside the UI thread, and start with nothing selected. Closing the review cancels further target generation. There is no automatic acceptance or calibrated confidence claim.

An additional experiment measured horizontal/vertical stroke contrast and selected constructions using only supplied controls. It did not improve the aggregate and slightly regressed Chalkboard, so it was not retained. No target glyph was used to select an individual suggestion.

## Does supplying more references solve it?

The audit now supports `--starter-reference-count 5|8|12`, `--starter-common-targets`, and `--starter-report /absolute/path/report.html`. The report overlays truth and suggestion at identical coordinates and includes per-letter scores and editing-anchor counts.

For the reference-count experiment, all runs score the same **40** target letters, excluding the twelve possible references. Five references are H O n o p; eight add a g S; twelve also add N R i t.

| Supplied references | Nine-face mean on the common 40 targets |
| --- | ---: |
| 5 | 52.8% |
| 8 | 52.9% |
| 12 | 53.2% |

These values must not be compared directly to the 47-target mean above. The small gain shows that the present procedural generator does not make sufficient use of richer references. A broader learned/vector inference approach and family-disjoint evaluation are still necessary research steps, not completed features. See the [quality plan](FONT_LAB_QUALITY_PLAN.md).

## Editor changes

- **Paths → Split at selected node** opens a closed contour at that node or splits an open contour's interior node, preserving every original segment and handle.
- **Paths → Join selected endpoints** joins two open contours or closes a contour. Coincident endpoints merge without inserting a zero-length segment; separated endpoints get a straight bridge. Existing curves remain intact.
- **Paths → Insert segment midpoints** uses exact cubic subdivision; adding editing points does not change the curve.
- **Transform → Distribute nodes horizontally/vertically** spaces at least three selected anchors evenly and translates their handles with them.
- Undo/redo is kept separately for each letter in the current project session, including bearing edits. Switching letters no longer discards history. With no history, Undo is disabled and cannot remove saved artwork. Histories are bounded by step count, active glyph count and retained geometry; project/setup/import changes reset them.
- Coordinate fields clearly name their units and disable when no nodes are selected. Operation feedback remains visible in object mode.

Regression tests check sampled curve equality after splits/midpoints, coincident joins, handle translation during distribution, independent glyph histories, source preservation and complete/exportable suggestions. Live disposable-project checks verified A's X3→X4 edit, switch to B and back, Undo→X3; splitting a 10-node contour gave 11 open nodes, and joining returned 10 closed nodes.
