# Spaces live interaction verification — 0.59.19 (99)

Canonical 0.59.19 (99) installed and verified. Public distribution verification is in progress.

## Live tests

Tested the installed 0.59.18 app in its disposable `--window-qa --spaces-interaction-qa` project using native UI actions. No user library/project data was used.

- Copy/cut/paste and paste in place create independent shape objects. Paste undo removes the copy; redo restores it. Grouped objects paste into the detached editor with their membership retained.
- Right and bottom shape handles independently changed a 180 × 100 object to 210 × 120. Dragging then placed it at fractional coordinates 83.5, 78.5 without grid snapping. The canvas stayed 640 × 480.
- Pasted text supports Auto-mode double-click editing. Ordinary text copy/paste while editing changes text rather than creating an object. The source text remains unchanged.
- Marquee selection, Command-G grouping and Shift-Command-G ungrouping work. Clicking one member after deselecting selects the whole group; after ungrouping it selects one object.
- All six canvas alignment buttons were exercised on a single shape, a two-shape group and an editable text object. Repeated centering was stable. Saved geometry confirms fixed canvas dimensions, unchanged object sizes, preserved group offsets and unchanged unselected text.
- Horizontal text reflection is visible. The quadrant mirror command creates three independent copies at the opposite canvas corners.
- Auto boundary selection reveals frame handles and clears object selection. A 47 × 37 screen-point boundary drag moved the canvas without snapping. Selecting an object clears the frame handles.
- Manual Select/Text/Canvas/Auto shortcuts, canvas focus, pop-out and redock shortcuts work.

## Regressions found and repaired

1. Widening a canvas after bottom alignment grew its height from 480 to 492 because the resize fit check added 12 pixels of artificial padding. Fit checks now use the actual text bounds. Native regression cases cover bottom-aligned widening and zero-distance resizing with right-aligned text at three canvas scales.
2. Popping out Spaces or undoing could clear the first responder, so object clipboard commands needed another click. App-level responder fallback routes object copy/cut/paste/select-all to the active Spaces editor while preserving normal text responders.

Final native suite, window tests, Figma bridge mocks, all eight website tests and live replay passed. Installation and read-only DMG verification passed; public distribution verification is pending. Private evidence: `.context/qa-artifacts/spaces-05918/live/` and `.context/qa-artifacts/spaces-05919/`.

Limits: these are native mouse/keyboard automation checks, not physical trackpad feel measurements. Alignment buttons currently align the selection as one unit to the canvas; they do not align selected objects against each other. Live Figma/Adobe host round trips were not part of this follow-up.
