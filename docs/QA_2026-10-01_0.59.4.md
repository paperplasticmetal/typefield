# Typefield 0.59.4 Spaces compact polish QA

Date: 2026-10-01 (Pacific). Build: **0.59.4 (84)**. This is a local ad hoc signed build, not a public distribution build. Missing-letter suggestions remain hidden.

## Design review

The five default formats were rendered as vector PDFs and reviewed at 320, 390 and 960 px. Private PDF and PNG previews are under `.context/qa-artifacts/spaces-template-polish-0594/previews/`; they are not committed.

| Format | Focused change |
| --- | --- |
| Website | The bag count reaches the right content edge while the navigation links keep their own frame. Older customized combined navigation stays in its saved frame without a second bag label. |
| Product UI | Quick capture keeps its Save label on compact canvases. Three summary numbers now share a baseline even when their captions wrap differently at 320 px. |
| Editorial | The illustration caption describes the letterforms and ink swatches actually shown. |
| Poster | Compact canvases retain the three-day program and its small edition line after date and venue. |
| Type system | A “FIGURES / 12” label identifies the numeral tile and fills an otherwise unexplained gap on compact canvases. |

The changes retain established section and text identifiers. No user Space, Library, Letterform Editor or font file was edited for the design review.

Strict deep signature verification passed, and the installed and tested `dist` executables have the same SHA-256: `65438c39c26507e8d4af9990d0128e4a3bfb8815f8b71a83ab22c0587bb70ce0`.

## Limits and release gates

These are default example compositions, not a claim that the templates replace a designer's own artwork. The separate Custom layout's long default display word may still widen a 320 px artboard to 375 px under the existing unbreakable-text rule. Distribution signing, a TestFlight or second-Mac/macOS 13 pass, live Figma/Adobe host round trips, and a full current-version accessibility and keyboard interaction matrix remain open in the [App Store checklist](APP_STORE.md).
