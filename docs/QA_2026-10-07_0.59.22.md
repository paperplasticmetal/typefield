## Changes

- A single scrollable icon rail provides interaction tools, insertion and Properties, Typography, Layers and Canvas panels. The upper strip retains document/view/export controls; selection and symmetry no longer repeat there.
- Flip controls use icons. A separate mirrored-copy menu keeps duplication explicit.
- Live pink guides match canvas and unselected object edges/centers during translation and resizing. Snapping uses a six-view-point threshold at every zoom; Option bypasses it. Group members are excluded as targets, and canvas bounds remain fixed.
- Shapes and text support blur plus colored, adjustable shadows. Object effects persist through save/reload, copy/paste, grouping and transforms. Mixed selections change only the effect property being edited.
- Preview PDFs retain effects; affected objects are rasterized with bounded resolution. Unaffected PDF objects keep their existing vector drawing. Editable Figma, Adobe and developer handoffs omit effects and disclose that limitation in the export review.

## Limits

Alignment guides target edges and centers; equal-spacing distribution guides are not included. This pass does not add an align-to-selection mode. The cache is limited to 32 MiB/32 entries and each effects raster to four million pixels/4,096 pixels per edge. Effects can soften at extreme export magnification. Physical trackpad feel and live external host round trips require separate testing.
