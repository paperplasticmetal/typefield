# Typefield 0.55 stress-audit fixes

This release addresses QA-01 through QA-06 in the [0.54 adversarial audit](STRESS_AUDIT_2026-09-27_0.54.md). It does not establish 90% suggestion confidence or professional font-editor parity.

## Changes

- **Object alignment:** alignment and distribution distinguish Objects from Nodes. Objects translate rigidly, including their handles and contained counters. A single object cannot be aligned to itself; the menu disables that action. Partial node selections carried into Objects mode resolve to complete compound objects.
- **Bubble counters:** narrow, heavy A constructions reserve room for the counter, and generated stroke overlaps are normalized into closed outlines. Source drawings stay untouched. Handwriting/bubble variants check for a useful counter region, a retained crossbar, and exportable geometry.
- **Long Spaces text:** paragraph sizing scans each paragraph once, with a bounded cache of repeated attributed-token widths. Editorial templates repeat only short sample copy; long articles stay intact once per column. Font summaries reuse the same bounded layout cache as canvas rendering. The cache has both entry and text-volume limits.
- **Dense outline recovery:** eligible 30,000-anchor outlines can use a bounded polygon-reduction stage before cubic fitting. Fits are still checked against the full source for boundary deviation, winding, containment, crossings and filled-ink agreement. Pixel masks replace repeated point-in-path scans for the silhouette check. Cancel stops the background fitting task. Pathological geometry can still be refused safely rather than frozen or silently distorted.
- **Many-canvas headings:** headings stay on one line at a fixed UI height. Dimensions and secondary actions appear when there is room; full names and editing state remain available through hover text and accessibility. Canvas tabs and the visibility menu remain available at small zoom scales.
- **Large Library previews:** cards show at most three lines, including overlays, with an ellipsis for overflow. Card width is capped so long strings do not monopolize the grid. **Expand preview…** opens the full text in the font inspector; stored preview text is not shortened.

### Suggestion quality remains a release gate

The same nine installed development faces still generate all 47 held-out glyphs per face. Rounded aggregate silhouette overlap remains **56.1% for the original five faces and 51.5% across nine**. Per-face scores: Helvetica 63.8%, Times 51.1%, Courier 53.4%, Menlo 59.2%, Avenir 52.8%, Chalkboard 62.3%, Noteworthy 38.1%, Marker Felt 66.1%, Snell Roundhand 16.3%. These are shape-overlap measurements, not calibrated prediction confidence. The local overlay report and logs were retained for comparison. Fixing the bubble counter does not establish 90% accuracy or reliable connected-script completion.
