# Typefield 0.52.0 — letterform fidelity and editability

This pass improves the local procedural starter assist and the outline importer/editor. It does not add a trained model or a probability of correct letter design.

## Method

The previous 0.51.0 implementation was rebuilt from Git alongside the expanded audit. Both versions see only H, O, n, o, and p from each installed face; the other 47 Latin letters are held out. The score is sampled intersection-over-union of filled silhouettes in the same coordinate frame. Width and spacing errors affect the score. This is a small development benchmark, not general handwriting accuracy. The historic 19.0% → 44.6% figure described this metric on the original five faces.

Original, independently drawn SVG fixtures exercise uneven handwriting (nopij, including offset i/j dots) and irregular bubble letters (BO). These pass through SVG rendering, PNG reading, segmentation, tracing, curve fitting, project encoding/decoding, suggestions, and TrueType export. OCR is disabled so geometry failures cannot be confused with label recognition; arbitrary handwriting recognition is not validated by these fixtures.

Mean suggestion density is approximately 20–25 anchors, with a maximum of 82 in this release's audit.

## Import and editing checks

| Fixture | Polygon anchors | Fitted anchors | Reduction |
| --- | ---: | ---: | ---: |
| Handwriting nopij | 4,114 | 250 | 93.9% |
| Bubble BO | 5,484 | 105 | 98.1% |
| Smooth two-contour curve | 480 | 13 | 97.3% |
| Subdivided existing Bézier | 64 | 4 | 93.8% |

Every handwriting/bubble glyph retained more than 97.5% sampled silhouette overlap against its unsmoothed import in the same frame. The tests also preserve counter/contour counts, detached marks, persistence, export, and existing artwork. The handwriting test initially exposed an offset-dot segmentation failure and excessive pixel-corner retention; both have regressions. Visual specimen review also exposed reversed lean in reflected n/u forms; reflection now restores the measured lean, with a dedicated slanted-n regression.

A read-only copy of the existing 26-letter local alphabet was also tested at the opt-in five-unit tolerance: total anchors fell from 11,514 to 2,390, with a median of 66 instead of 458. Twenty-four glyphs became simpler; two retained their original geometry. Minimum sampled filled-silhouette overlap was 96.4%. Open editing paths remain intact and are excluded from filled-silhouette comparisons, matching the editor's fill/stroke behavior. No changes were applied to that saved project. This stronger setting trades some detail for fewer controls and remains a reviewed preview.

The fitter bounds geometric deviation in physical font units, retains winding and containment, rejects crossings, checks filled-ink agreement in both the original and union frames, and never accepts more editing anchors. Simple existing curves remain intact. Automatic import uses 1.5 source pixels, bounded to 1–3 font units. Suggestion copies use 2–3 units. The five-unit option is available only through Smooth trace review.

## Remaining limits

Connected script and design choices absent from the seed letters remain weak. Reusing a bowl or reflecting a stem does not establish whether the intended a/g is single-storey or double-storey, nor infer swashes or contextual joins. Some serif holdout results regress even when the overall average improves. Templates remain explicitly provisional; full-font shape, spacing, and word proofing are still required.

The SVG importer continues to render and trace; it is not lossless import of original SVG control handles. Touching letters, decorative backgrounds, and ambiguous detached marks can still need manual regions. This release's live mouse/trackpad editing interactions have not been exhaustively retested.
