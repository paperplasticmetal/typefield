# Typefield 0.59.11 (91) layout verification

Window and focus actions moved into a shared View menu within each workspace’s project toolbar. Spaces now has one project toolbar and one canvas strip; the separate window and space action rows are gone. Letterform groups setup/import under Project and uses a single glyph header with undo/redo and a Glyph menu. Selection transforms, preview appearance and sketch brush settings open on demand. Their shared navigation sidebar uses the same shell, width, outer padding and top origin as Library. Focus mode still hides surrounding workspace chrome as before.

Expanded Metrics & spacing uses the full drawing-column width. A responsive layout lays out the illustration, vertical metrics and side bearings in up to three columns, stacking at narrower widths. Focused editors constrain content to the window width instead of using an unbounded horizontal scroll view. The normal full-workspace side inspector retains its 232-point width. Slider bindings, saving, history, window reparenting and font drag interactions are unchanged.

Spaces typography now has direct Paragraph and Font features & pairing sections, numeric preset labels, a named case picker and clearly labeled Text & proofing controls. Existing editing, saving and undo actions are retained. The user confirmed the 0.59.10 window interactions and requested this broader toolbar organization before publication. The pre-existing research edits remain separate, and research stays paused.
