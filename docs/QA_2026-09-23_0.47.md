# Typefield 0.47.0 focused QA — 2026-09-23

Build **0.47.0 (64)** on Apple Silicon macOS **26.3 (25D126)** with Xcode 26.6. The live app used `CFFIXED_USER_HOME=/private/tmp/typefield-047-qa`; its space, watched folder and imported JSON were disposable. Existing fonts and saved user projects were not edited. `LIVE PASS` means the interaction was exercised in that isolated app; `AUTOMATED PASS` means a named fixture or build check passed. Neither status certifies other operating systems or third-party applications.

| Area | Status | Evidence |

| Native build and data checks | AUTOMATED PASS | `bash build.sh` compiled with Swift warnings as errors, signed the local app and passed the built-in suite.
