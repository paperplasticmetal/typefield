# 0.59.12 verification

Version 0.59.12, build 92. Starting revision `fd2361f`. Preserve both pre-existing research-script changes and all user font/project data. Research remains paused.

## Changes under test

- Board menu contains actions, without checkpoint count/retention text rows.
- Export opens a configuration window with format, file/detail and scope dropdowns, canvas checkboxes, structured typography preview and compact compatibility review: shown, all, current or selected canvases. Selection is filtered against existing IDs and ordered as in the board; cancel performs no export. Preview PDF is multipage with original page sizes. Figma and developer handoff receive a scoped board without checkpoint snapshots.
- All frame drag gestures use a stationary workspace coordinate space. Manual resizing retains its initial zoom instead of snapping back into Fit width; left/top frame positions account for canvas scale. Live geometry is computed once per canvas per update.
- Remove the unresponsive tear-off grip; retain explicit View > Pop out editor / Dock window.
- Local activation actions use the existing Core Text session journal. System/external fonts cannot be deactivated through those actions. License-source links are limited to web URLs without embedded credentials. Personal/team licensing, price estimates and provider account connections are not implemented; see [provider integration requirements](FONT_LICENSING_INTEGRATION.md).
