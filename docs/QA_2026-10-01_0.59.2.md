# Typefield 0.59.2 local release refinement QA

Date: 2026-10-01 (Pacific). Build: **0.59.2 (82)**. Scope: Library grid spacing, new Spaces paper color, copy cleanup, navigation performance and release positioning. This is a local ad hoc signed build, not a public distribution build. Missing-letter suggestions remain hidden and their research files remain available locally.

## What changed and what was checked

| Area | Result and evidence |
| --- | --- |
| Library grid | The previous installed build reproduced unequal card bottoms in the same row at 137 pt, including the mixed-script row. The installed 0.59.2 app showed aligned bottoms and shared preview baselines at the user's 133 pt single-`r` setting. A Japanese preview also kept card rows aligned when Core Text used fallback glyphs. The preview was restored to `r` after the check. Row measurement runs within visible lazy rows and caps measurement at three lines and 512 characters per font. |
| Spaces canvas | A new `TypeDirection` starts with `#FFFFFF`. Native checks rendered the new white canvas and round-tripped/rendered a previously saved `#F5F2EA` canvas without recoloring it. The live existing warm board retained its chosen paper. |
| Interface copy | Centered-dot separators were replaced in active submenus, status labels, inspector text, samples and exported handoff copy. Persistent `WritingSystem` raw values were retained for saved filters/tags; their display names are cleaner. Actual rich-text list bullets and the visual ellipsis-menu symbol remain. The installed Spaces toolbar and edit-scope wording were inspected. |
| Navigation and decluttering | Library footer now reuses the visible family filter result instead of filtering and sorting the full catalog again. Spaces toolbar computes the visible font summary once per toolbar render. The existing synchronous selection save was retained because disposable timings did not show a release-size bottleneck and it protects persistence and rollback. |
| Native and bridge checks | `./install-local.sh` reran `bash build.sh`: all built-in checks passed, including 21,260 font layouts, Spaces rollback, artwork/font export, backup recovery and responsive canvas fixtures. `node tests/figma-import.test.js`, Swift syntax parsing, plist lint and `git diff --check` passed. |
| Installed app and data | The single canonical `/Applications/Typefield.app` is 0.59.2 (82), passed strict deep code-signature verification, and its executable hash matched the tested `dist` build. The four saved Library, pro Library, Spaces and Letterform Editor JSON files matched their pre-work SHA-256 values after installation and UI review. |

## Disposable performance audit

One local optimized run on this Mac; milliseconds are timings of native code paths, not end-to-end animation or computer-control time. Fixtures were removed afterward.

| Spaces fixture | JSON size | Fresh store load median / p95 | Typeboard selection save median / p95 |
| --- | ---: | ---: | ---: |
| 2 simple boards | 3 KB | 0.110 / 0.265 ms | 0.591 / 1.235 ms |
| 50 simple boards | 64 KB | 1.992 / 2.076 ms | 2.441 / 2.653 ms |
| 200 simple boards | 256 KB | 8.189 / 8.779 ms | 8.081 / 8.420 ms |

The same run measured a 2,747 ms cold font-catalog scan over 778 families and 4,252 styles; a Library filter pass took 4.1 ms, and a sidebar count snapshot took 3.4 ms. A full uncached editorial canvas plan took 3.0 ms; cached reads were below 0.001 ms in this microbenchmark. These results do not isolate SwiftUI layout/render time or guarantee performance on another Mac or unusually dense imported boards. No data migration or asynchronous save redesign was introduced for this release.
