# Typefield 0.59.6 interaction and efficiency QA

Date: 2026-10-05. Baseline: `c30a478` (0.59.5). Target: 0.59.6 (86), native arm64.

## Scope and isolation

Three workers reviewed Library, vector editing, and Spaces/persistence with coordinator integration. This continues the 0.59.5 runtime cleanup; it does not resume letterform model research. Production font files were not edited or registered. All writable live tests used a separately sandboxed temporary QA app and disposable projects. Its executable was copied from the compiled application and re-signed under a QA identifier; code-signature metadata therefore differs. Only `/Applications/Typefield.app` is the installed release.

The six production saved JSON hashes were unchanged, and the two pre-existing research edits remain byte-identical and uncommitted. Private evidence is in `.context/qa-artifacts/interactions-0596/` and worker evidence in `.context/qa-artifacts/interaction-2026-10-05/`. No private evidence belongs in Git.

## Fixed findings

- Renaming a collection left collection-scoped saved searches pointing at its old name. Rename now updates those references in the same save and rolls them back on failure. Existing orphaned searches from earlier renames cannot be reliably inferred and are not automatically reassigned.
- A cancelled SwiftUI glyph-browser task left its detached Unicode scan running. Cancellation now reaches the worker, which polls during mapping and glyph enumeration and discards partial results.
- Object selection rebuilt the outer contour for every candidate node. It now builds paths and bounds once per contour. A 10,600-anchor object/counter selection completed in 30.395 ms in the first optimized combined run; this is a bounded fixture, not an all-interaction frame-rate claim.
- Interrupted vector drags could leave provisional geometry or replay stale snapshots. Escape restores the starting outline/selection, recognized edits finish the gesture once, unrelated keys leave it active, and completion releases drag snapshots.
- Editable vector accessibility elements incorrectly inherited a disabled state. Nodes and contours now explicitly report enabled.
- Failed Spaces Undo/Redo preserved the document but consumed history. Group replay now persists once; failed writes restore document, focus, timestamps, action labels and both history stacks for retry. An independent reviewer reran default event-grouping tests.
- Selecting the already focused board unnecessarily saved. Navigation now skips that write and ends numeric-edit coalescing only when focus changes successfully.
- Font choice/pairing/discovery could announce success after a failed save. Success and usage recording now require a successful save.
- Corrected singular family/style wording in collection and tag/family tools.

## Automated validation

`./install-local.sh` runs the optimized native suite before installing the canonical app. The first combined run passed 21,260 typography layouts across 778 families/4,252 styles, 33 responsive canvases, font health/export, geometry, backup interruption/rollback, migration, folder watching and persistence checks.

New regressions cover cancelled glyph scans, saved-search rename and failed-save rollback, gesture Escape/Undo/unrecognized-key sequences, accessibility enabled state, dense object selection, bounded history/redo abandonment, rapid navigation/edit separation, redundant selection saves, and repeated Undo/Redo failure/retry with grouped dependent deletions. Isolated production-store harnesses also passed default event-based grouping with both history stacks populated.

`node tests/figma-import.test.js` passed editable layers, typography, fallback, validation and rollback. It uses a mocked Figma API; no live Figma/Adobe host integration is claimed.

## Limits

This is a substantial targeted interaction pass, not exhaustive verification of every sequence. No second Mac/macOS 13 run, continuous Instruments energy/frame-time capture, live Figma/Adobe round trip, new Google Fonts download, in-place original-font repair, or persistent font activation was performed in this pass. Native tests cover several of those underlying file/data operations with disposable fixtures. Coordinate-based live dragging encountered the automation tool's window-position error; interrupted drag sequences were exercised by the native event regressions instead. Tiny wording issues outside the corrected Library tools (for example “1 nodes”) remain cosmetic follow-up work. Distribution signing/notarization is separate from the local ad-hoc signed installation.

## Final installation

The final `./install-local.sh` run passed the complete native suite and installed 0.59.6 (86). Dense 10,600-anchor selection measured 29.099 ms in that run. The Figma mock bridge and whitespace checks passed again. Strict code-signature verification passed, and the installed executable matches the tested build: SHA-256 `1ce8e0417f5018c6775f7cdd45461b14bc8ca660dfd29fa1a08e1b7071b1025c`. Both version plists agree. Final production-data hashes and the interrupted research diff remain unchanged. Live exported SVG/backup files parse, and four export fixtures are preserved privately.
