# Typefield 0.59.3 Spaces template refinement QA

Date: 2026-10-01 (Pacific). Build: **0.59.3 (83)**. This is a local ad hoc signed build, not a public distribution build. The paused missing-letter suggestions remain hidden.

## Design review

The five default Spaces formats were rendered to vector PDF and visually reviewed at 390 and 960 px. Private previews are under `.context/qa-artifacts/spaces-template-refinement-0593/previews/`; they are not committed with the project.

| Format | Refinement |
| --- | --- |
| Website | A small product shop with a split introduction, vector lamp, featured solid-ash stool, concrete product copy, two journal stories and a newsletter footer. All three stories remain present on narrow canvases. |
| Product UI | A working review queue with summary numbers, project states, a selected-project detail and next action, plus quick capture. Narrow canvases stack the detail below the list. |
| Editorial | A magazine feature with byline, proof-sheet illustration, continuous article and a short pull quote. The article no longer repeats the default paragraph across columns. |
| Poster | A type-led event sheet with date, venue and program in a colored rail at wide widths, then a compact date/venue arrangement at narrow widths. Rail text adapts when the accent and ink colors match. |
| Type system | A specimen sheet that labels each role, font and size. Its default display uses letter pairs and a numeral tile; individual type samples remain editable. |

No user Space, Library or Letterform Editor file was edited for this review. Existing section IDs and the established editable text IDs remain stable. A legacy Editorial second body frame is retained when either its text or position was saved.

Its responsive checks cover the five default formats at **320, 390, 768, 960 and 1200 px**, text fit, separation, section reorder/hide, and correctly sized PDF pages.

- `node tests/figma-import.test.js`, both plist lints and `git diff --check` passed. The Figma check uses a mocked API; it is not a live host-app round trip.
- `./install-local.sh` reran the optimized suite and installed the single canonical `/Applications/Typefield.app`. Its Info.plist reports **0.59.3 (83)**; strict deep signature verification passed. The installed and tested `dist` executables have the same SHA-256: `7fddb2c089b89b474e8577aaa2fbe2490ad72ad833bc1023b239a375149ad0d1`.
- The four existing Library, pro Library, Spaces and Letterform Editor JSON files matched their pre-work SHA-256 values after installation.

## Limits and release gates

The illustrations are deliberately lightweight vector examples. They give the templates specific content and survive the native/PDF composition path, but users may still replace them with their own artwork. The separate Custom layout's default long display word may widen a 320 px artboard to 375 px under the existing unbreakable-text rule; this template pass does not change that behavior.

Distribution signing, TestFlight or second-Mac/macOS 13 verification, host-app Figma/Adobe round trips, and the full current-version accessibility and keyboard interaction matrix remain open in the [App Store checklist](APP_STORE.md) and [production readiness audit](PRODUCTION_READINESS.md).
