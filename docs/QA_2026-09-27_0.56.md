# Typefield 0.56 suggestion refinement

The user requested at least 85% confidence. **That target has not been reached.** These audits measure fixed-coordinate silhouette IoU, not calibrated confidence or user acceptance. The production generator remains a local deterministic outline constructor; no learned checkpoint or font-retrieval backend has been installed in the app.

## Kept changes

Eligible D/E/F/I/L suggestions reuse the supplied H stem, retaining its curve terminals and physical weight. D also reuses the supplied O's right-hand curve. Crossbar thickness is measured from H. Reboxing preserves the original ink position and margins. Rounded/irregular stems retain the previous construction, and monospaced I retains its identifying-bar construction. Every result remains independently editable; the source drawings are unchanged.

An initial unguarded version regressed Chalkboard I, so it was rejected. A later rotated-serif-terminal trial also failed to improve the aggregate and was removed. The shipped method is the validated source-stem version, not either rejected trial.

## Development measurements

References remain H O n o p; all 47 other letters are scored per face. Missing predictions count as zero. Targets are never used to choose a proposed shape. At the original 92 × 72 grid, the nine-face mean improves from **51.5% to 52.3%**. At 368 × 288 it improves from **51.5% to 52.4%**. The candidate has **33/423 letters at least 85% overlap** at both resolutions; the worst style is still 16.3%.

## Stronger model/prior experiments

- **Installed-font reference retrieval:** 3,994 candidate faces, excluding all nine known target family lineages; ranking uses only supplied references. Rank-1 mean is 60.9% on the audit's sample grid. Unrelated families can contain close Latin clones, and the research harness has a different direct-outline normalization path, so this is not proof of generalization to novel artwork. It is not included in the app. The reproducible harness is in `scripts/starter-research/`.
- **Optional spacing calibration and separate-case retrieval:** both regressed (58.5% and 58.5% respectively) and were rejected.
- **Reference-fitted distance-field mixture:** 65.3% versus a 63.6% single-candidate comparator at 128 × 128 raster resolution. This is not the production metric and has not passed vector editability validation. It is not shipped.
- **DesigNet checkpoint trial:** the official checkpoint uses eight different references (Hamburge), four contour slots and a 32-command decoder. Strict weight loading succeeded using the restricted tensor loader, after excluding an unused training-loss buffer. Extending only the analytic input position buffer allowed longer references; canonical contour winding/start positions improved the trial, but several cases still had empty predictions and the resulting fidelity was poor. Unsupported/empty outputs were not treated as successes. This exploratory adapter is not a native integration or a fair replacement for the five-reference baseline. Checkpoint revision: `231d16f537daf1f264505f01fdf2828bb2985f35`.

Research stayed local; no user drawing or font was uploaded. Temporary masks, checkpoints, model environments and overlay artifacts are not part of the repository or application. Primary model implementation: [DesigNet](https://github.com/TomasGuija/DesigNet).

## Verification and reproduction

The source tests cover compact anchor counts, source preservation, physical ink insets/position, extreme spacing limits, monospaced I, and TrueType export. Existing handwriting/bubble counter and dense-import checks remain in the native suite. There were no UI or storage changes in this round.

```sh
bash build.sh
node tests/figma-import.test.js

dist/Typefield.app/Contents/MacOS/Typefield --starter-quality-audit
dist/Typefield.app/Contents/MacOS/Typefield --starter-quality-audit --starter-grid-scale 4
dist/Typefield.app/Contents/MacOS/Typefield --starter-quality-audit --starter-validation-set
# Same executable, original construction for the controlled comparison:
dist/Typefield.app/Contents/MacOS/Typefield --starter-quality-audit --starter-disable-stem-reuse
```

The audit now reports aggregate and worst-face scores, threshold coverage, and incomplete availability explicitly. `--starter-report` writes the visual overlay report. Missing required faces cannot silently turn an incomplete audit into a passing result. A 100% sampled overlap is not a proof of identical curves.

The final optimized native suite passed **21,260 layouts across 778 families / 4,252 styles**, including the new large-inset and wide-monospaced fallback checks. The unsigned Xcode Release build and mocked Figma bridge passed. `./install-local.sh` installed the single canonical **/Applications/Typefield.app 0.56.0 (76)**. Strict signature verification passed; installed and dist executables share SHA-256 `6315d574c1ed9824809f1b28393747cd22d8d8cef4784a36bd9de676c37fd48d`. Both version plists agree. All three reported audits were repeated successfully with that installed executable. The four original saved library/project data files remain byte-identical to the pre-install and previous-release snapshots. No claim of a new interactive UI audit is made; the code change is in generation and its diagnostics.

Private evidence stays in `.context/qa-artifacts/letterform-056/`; its font outlines, raster masks and model outputs are not committed.
