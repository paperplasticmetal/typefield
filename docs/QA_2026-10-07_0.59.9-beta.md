# Typefield 0.59.9 beta verification

Build 89 was prepared on 2026-10-07 for the public beta. It targets Apple silicon and macOS 13 or newer. The app has an ad hoc signature and no account or license gate. It has not received Developer ID signing, notarization, App Store review or a clean second-Mac installation.

## Checks

- `bash build.sh` passed the native self-test, including 21,260 font layout cases across 778 families and 4,252 styles and the variable-font CoreText interpolation checks at weights 400, 550 and 700.
- `node tests/figma-import.test.js` passed with the Figma API mocked. Live Figma and Adobe host-app round trips were not performed.
- A second `--self-test` run wrote a disposable variable-font fixture. `python3 tests/variable-font-tables.py /private/tmp/typefield-0599-variable-fixture.ttf` independently verified sfnt checksums, `fvar`, `STAT`, `gvar`, varying A/O contours and the advance-width delta.
- `./install-local.sh` rebuilt, reran the native suite and installed the single canonical `/Applications/Typefield.app` at 0.59.9 (89). Strict signature verification passed. The installed and tested executables share SHA-256 `19ac747344a07ab0b3424e3952066fac96e46258732e8c7179c1e7057c08ec8e`.
- The 27 existing JSON files under the FontShelf Application Support folder retained aggregate SHA-256 `4442f258cf1dc830256d9e3725d75d3cdb7098b3d3e6829066d255a1beae1dee` before and after installation, using the same sorted per-file hash manifest command.
- `bash package-beta-dmg.sh` produced `dist/Typefield-0.59.9-beta.dmg` with SHA-256 `a89450c4d8010d9dcd3c6b3de6f596cfd1ed3aa454205fb2edc560762951518a`. `hdiutil verify` passed. A read-only mount contained Typefield 0.59.9 (89) and an Applications shortcut; the mounted app passed strict signature verification and its executable hash matched the installed and tested copy.
- The first-party feedback form submitted a disposable report from `typefield.app` in Arc. The report appeared in the private Cloudflare D1 inbox and was removed after verification. No GitHub login was needed.

## Current limits

Variable export supports exactly two compatible masters and one `wght` axis. It rejects mismatched character mappings, contour topology, winding, vertical metrics or kerning. It does not interpolate kerning or provide an intermediate-weight editor preview. No clean second-Mac install or macOS 13 first-launch test was performed. The macOS first-open exception was not exercised on this Mac.
