# Typefield 0.59.7 private beta verification

Build 87 was prepared for invited GitHub collaborators on 2026-10-06. It targets Apple silicon and macOS 13 or newer. The app has an ad hoc code signature, no Developer ID identity, and no notarization. Gatekeeper assessment rejects the bundle; testers must use the documented Privacy & Security first-open exception if macOS blocks it. No app account, activation key, or purchase gate is present.

## Checks

- `./install-local.sh` passed the optimized native self-test and installed one canonical `/Applications/Typefield.app`. The run covered 2,640 layout cases across 778 families and 4,252 styles, plus Library, Spaces, Letterform Editor, import/export, recovery, and settings checks.
- `node tests/figma-import.test.js` passed with the Figma API mocked. Live Figma and Adobe host-app round trips were not performed.
- `codesign --verify --deep --strict` passed on the built app, installed app, and app inside the DMG. The installed and built executables share SHA-256 `213f6a42040f47e36ae63ccf7f7716e7ccd8750d387fcfae6b182bd2ea1c3e94`.
- `bash package-beta-dmg.sh` produced `dist/Typefield-0.59.7-beta.dmg`. `hdiutil verify` passed. A read-only mount contained Typefield 0.59.7 (87) and an Applications shortcut; its executable hash matched the tested build. DMG SHA-256: `8b315a9c9f9a12ee75bf415831fbac3fe9cd8fc6dae8c4d4c8cf3612de79279c`.
- The 27 saved JSON files under the existing FontShelf support folder retained aggregate SHA-256 `99e9914c8b947d385fc37b0fc2c5d3fd1617fac97b830bf66050a619cd052a58` before and after installation.
- Help and About contain feedback and bug-report links to the repository's issue templates. The beta feedback template asks testers to redact personal data and avoid attaching proprietary font files.

## Remaining limits

No clean second-Mac install or macOS 13 first-launch test was performed. The security exception was not applied on this Mac. The private GitHub release and Cloudflare website deployment are tracked separately from this local build verification. This beta is not an App Store, TestFlight, Developer ID, or notarized release.
