# Typefield 0.53.0 — letterform fidelity and editable imports

## Scope

This pass addresses the dense imported A shown by the user, visibility of handwriting/bubble examples, and missing-letter shape similarity. Existing user projects and fonts are preserved. Practice edits use `CFFIXED_USER_HOME=/private/tmp/typefield-053-qa`; a copy of the user's A is used only in this disposable profile and private local QA artifacts.

## Editing and imports

- The actual saved A had 568 outer anchors, 140 counter anchors and a two-node open pen path: **710 total**. At the five-unit preview it now has **13 + 6 + 2 = 21 anchors**, retaining **97.99%** sampled closed-fill IoU against the original. The open path remains unchanged. This is import simplification fidelity, not missing-letter prediction quality.
- The root cause was duplicate corner detection across raster stair-step neighborhoods. Corner suppression now retains the strongest turn once, and straight spans become lines. Boundary-deviation, winding, containment, crossing and filled-silhouette checks still gate accepted results.
- A synthetic low-resolution rounded A independently reduces **554 → 21** anchors and retains its counter and open pen edit.
- Original handwriting import: **4,114 → 210** anchors. Original bubble B/O import: **5,484 → 75** anchors. Every tested glyph retains over **97.5%** sampled silhouette overlap. Checks also cover detached dots, counters, JSON persistence and TrueType export. OCR is disabled for these geometric fixtures; they do not establish recognition accuracy for photographed handwriting.
- Live native UI: the dense-point warning appears; **Simplify outline…** opens at **Editable · 5 units**; the A preview reports 710/21; Apply produces 13/6/2 nodes; Undo restores 568/140/2. A bubble B anchor moves from X176 to X177 units and Undo restores X176.
- A bitmap regression verifies translucent preview ink is composited once per glyph, so overlapping source strokes no longer produce dark seams. Live gallery review exposed this after the outline fixes.
- The sidebar gallery displays handwriting and bubble source/suggestion rows. Opening the bubble example creates a separate 52-letter practice project with provenance. These original synthetic examples do not provide ground-truth missing-letter designs.

## Suggestion changes

- Plain stems, letter-specific width proportions and separate optical spacing for diagonal, round and stem forms replace a uniform-width/uniform-bearing assumption where suitable controls are supplied.
- Stroke-width fitting is selected by how well each construction reproduces supplied control letters. No hidden target enters this calibration.
- e reuses o's bowl with a crossbar/opening. Horizontal reflections compensate for slant and rebox extended coordinates without clipping the outline. h extends the measured n stem along its lean, correcting the detached ascender found during live visual QA.
- Monospaced advances remain constrained; very thin outlines must retain complete proposal coverage.

## Measurement limits and next step

The fixed audit supplies only H O n o p and holds out 47 letters for each of nine installed faces. It compares ink in the same physical frame at the existing 92×72 sampling grid, including placement and width errors. These faces have informed development, so the result is a regression benchmark, not an untouched generalization test. There is no learned model or calibrated prediction-confidence percentage in this release. Most suggestions still use constructed templates. See [the path toward 90% shape overlap](FONT_LAB_QUALITY_PLAN.md) for the broader, family-disjoint vector-model experiment.
