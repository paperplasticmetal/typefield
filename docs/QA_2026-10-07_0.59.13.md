# Spaces interaction tools — 0.59.13 (93)

## Behavior

Select and Marquee share a content selection. Shift-click extends or removes objects, and saved groups select together. Drag selected content to move; the lower-right selection handle scales it proportionally. Arrow keys nudge; Shift-arrow moves by ten pixels. Selection menu provides select all, deselect, group, ungroup and transform reset. Native text editing/reordering remains in Text mode. Canvas mode targets only the boundary; editing a canvas alone no longer shows its outline or resize handles.

Frame gestures retain the workspace offset and current zoom when committed, preventing release-time recentering and Fit-width changes. Object gestures preview in the native canvas and commit once on release; Escape cancels. Transform/group fields are optional for older document decoding, and template source content stays editable. Uniform transforms are applied before canvas scaling to the rendered geometry used by visual/layout exporters. Persistent group membership remains Typefield document data; exports retain appearance without promising equivalent host-app groups.
