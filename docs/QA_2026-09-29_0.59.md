## Installed interaction review

- **Library:** Visually checked the adaptive card grid and family-specific accessibility names; opened the grouped Tools menu. The Last Import section with remembered but unavailable fonts now states **Recent import unavailable**, gives a folder/reimport route, and offers **Browse all fonts** without a dead Clear filters action.
- **Spaces:** Visually checked the persistent editing-scope explanation, grouped Type/Object/Canvas inspector, visible font count and literal **Fit width** control on an existing canvas. No existing typeboard was changed.
- **Letterform Editor:** Visually checked the docked word-proof strip, single simplify action for a dense outline and the character jump. Drawn and Empty filters showed only their respective tiles; jumping to a hidden glyph restored the All view. The TrueType review reported the mapped outlines, automatic blank space and omitted characters; the export was canceled before a file chooser. No glyph was changed.
